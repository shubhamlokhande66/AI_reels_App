# Shubix

Shubix makes beat-synced Reels from clips, photos and a song: the website [shubix.in](https://shubix.in) and the Android
app, with one account, one plan and the same studio.

Everything is in the pnpm monorepo [`shubix/`](shubix/README.md): `FE/web-app` (Next.js website), `FE/mobile-app` (Expo
Android app), `BE/api` (NestJS API) and `Shared/*`. Layout: [folderStructure.md](folderStructure.md).
