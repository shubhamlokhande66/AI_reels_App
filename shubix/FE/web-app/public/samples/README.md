# Sample clips for "Try it with our sample clips"

Put a song and 4-6 short vertical clips here, then add `manifest.json`:

```json
{ "song": "song.mp3", "songName": "Sample beat", "clips": ["clip1.mp4", "clip2.mp4", "clip3.mp4", "clip4.mp4"], "credit": "Music: <title> by <artist> (licence)" }
```

- Use only media you own or that is free to use (royalty-free music, your own footage). Keep the whole set under ~25 MB.
- Without `manifest.json` the button stays hidden.
- `/create/music?sample=1` starts the sample straight away (for a Home or ad link).
